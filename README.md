# Ilias Rais · personal website

Personal resume website of **Ilias Rais**, Software Engineer and Erasmus Mundus CYBERUS student (cybersecurity).

Engineer by training, cybersecurity by passion.

## Stack

Plain HTML, CSS and JavaScript. No framework, no build step, no trackers.

- `index.html` English version
- `fr/index.html` French version
- `styles.css` shared styles (self-hosted Inter and JetBrains Mono in `assets/fonts/`)
- `script.js` shared interactions: terminal preloader, network canvas, ICS lab simulation, stacking cards, scroll-scrubbed claim verification, FAQ accordion

## Run locally

```bash
python -m http.server 5173
```

Then open http://localhost:5173.
